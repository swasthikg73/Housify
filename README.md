# 🏠 Housify - Real Estate Application

Housify is a modern real estate web application built using the MERN stack.  
It allows users to explore property listings, post their own properties, and communicate directly with property owners through real-time messaging.

---

## 🚀 Features

- 🔍 Browse available property listings
- ➕ Add and manage property posts
- 💬 Real-time messaging using Socket.io
- 🔐 Authentication & Authorization
- 📱 Fully responsive design
- ⚡ Fast and scalable backend with Node.js
- 🗄️ Prisma ORM for efficient database management

---

## 🛠️ Tech Stack

### Frontend
- React.js
- CSS / Responsive Design
- Axios

### Backend
- Node.js
- Express.js
- Prisma ORM
- MongoDB

### Real-Time Communication
- Socket.io
